# 账号余额

买家和商家共用 `user_wallets` 表，通过 `user_id` 主键分别持有独立余额，不共用资金。注册事务已经负责创建零余额钱包，不在用户表重复保存余额。

- `GET /api/v1/wallet/balance`：查询当前登录账号的余额，返回 `data.balance`。不接受指定其他账号的查询目标。
- `GET /api/v1/user/me`：个人资料额外返回 `balance`。待审核商家仍可查看自己的资料和零余额；充值和钱包接口沿用审核状态限制。
- 现有 `POST /api/v1/wallet/deposit` 继续使用本地模拟充值能力，登录账号给自己的钱包充值。商家和买家余额分别存储，不因身份共享而混在一起。
- 管理员审核列表和申请详情不额外暴露账号余额。

迁移只为历史上缺少钱包的账号创建零余额记录，已有余额不会被覆盖，支持重复执行。尚未实现订单支付扣款、商家收款、提现或真实支付渠道。
